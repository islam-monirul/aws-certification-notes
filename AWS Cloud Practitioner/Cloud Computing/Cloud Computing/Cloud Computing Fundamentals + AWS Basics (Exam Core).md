Cloud computing = **rent IT resources over the internet on-demand** instead of owning them.

-    No upfront cost
-    Pay only for what you use (**pay-as-you-go**)
-    Scale resources anytime

---

## What is Cloud Computing?

Cloud computing provides:

-    Compute power (servers)
-    Storage
-    Databases
-    Applications

### Key Concept

-    **On-demand**
-    **Pay-as-you-go**

---

## Traditional IT vs Cloud

| Traditional (On-Premises) | Cloud             |
| ------------------------- | ----------------- |
| Buy hardware upfront      | Rent instantly    |
| Guess capacity            | Scale anytime     |
| Maintain servers          | AWS manages       |
| Slow setup                | Launch in seconds |

---

## Types of Cloud

### 1. Private Cloud

-    Used by a single organization
-    More control and security

### 2. Public Cloud

-    Owned by providers like AWS, Azure, GCP
-    Most common in real-world and exam

### 3. Hybrid Cloud

-    Mix of private + public cloud
-    Balance of control + flexibility

---

## 5 Characteristics of Cloud (Important)

1. **On-demand self-service**
2. **Broad network access**
3. **Resource pooling (multi-tenancy)**
4. **Rapid elasticity & scalability**
5. **Measured service (pay per use)**

---

## Advantages of Cloud

-    Trade **CAPEX → OPEX**
-    Benefit from **economies of scale**
-    No need to guess capacity
-    Faster deployment (**agility**)
-    No data center maintenance
-    Global infrastructure access 🌍

## Cloud Service Models

### IaaS (Infrastructure as a Service)

-    You manage: OS, apps, data
-    AWS manages: hardware

**Example:** EC2  
👉 Like renting an empty apartment

---

### PaaS (Platform as a Service)

-    You manage: application + data
-    AWS manages everything else

**Example:** Elastic Beanstalk  
👉 Like a ready kitchen

---

### SaaS (Software as a Service)

-    AWS manages everything

**Examples:**

-    Gmail
-    Dropbox
-    Zoom

👉 Like ordering food 🍔

## AWS Pricing Fundamentals

-    **Compute** → pay per usage time
-    **Storage** → pay per GB stored
-    **Networking** → pay for data leaving AWS

👉 Data IN = FREE  
👉 Data OUT = PAID
